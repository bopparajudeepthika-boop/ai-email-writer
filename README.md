# AI Email Writer ✉️

AI Email Writer is an AI-powered web application that uses Google Gemini to generate professional and personalized emails quickly and easily.

## Features
- AI-powered email generation
- Professional email drafts
- Simple and user-friendly interface
- Copy generated emails easily

## Technologies Used
- Google Gemini AI
- Frontend technologies used in this project
- Replit
- Git and GitHub

## How to Use
1. Enter the purpose of your email.
2. Select a tone if available.
3. Generate your email.
4. Review and edit the generated content.
5. Copy your email.

## Objective
To make email writing faster and easier using artificial intelligence.
